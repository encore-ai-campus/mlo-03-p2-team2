## 특이 만료일과 실제 점검 매칭

인허가 Silver에서 만료 연도가 1995~2030년 밖인 기록 6건을 찾았습니다. 이 범위는 이 스냅샷의 분포를 확인하는 데 사용했습니다. 해당 면허번호의 인허가 이력 13건, 전체 점검 318,552건, Gold의 확정 기록 ID와 기간 후보 조건을 대조했습니다.

| 만료일 | 인허가 이력 | 같은 면허번호의 점검 | 실제 기간 후보 | 확정 연결 | 판정 |
| --- | ---: | ---: | ---: | ---: | --- |
| `0206-08-17` | 1 | 0 | 0 | 0 | 시작일보다 빨라 기간 역전 규칙에 해당합니다. |
| `1901-01-01` | 4 | 0 | 0 | 0 | 4건 모두 기간 역전 규칙에 해당합니다. |
| `9999-01-01` | 1 | 0 | 0 | 0 | 기간 순서 검사에는 통과합니다. 같은 면허번호의 점검이 없어 후보로 계산되지 않았습니다. |

`9999-01-01`의 인허가 기록 ID와 면허번호는 `2992907`입니다. 시작일은 `2024-09-25`, 상태는 `AAC`(취소), 상태 변경일은 `2026-05-29`입니다. 6건을 기간 후보에서 제외했을 때 매칭 결과가 바뀌는 점검은 0건입니다. [시카고시 인허가 상태 설명](https://catalog.data.gov/dataset/business-licenses)

## 결정이 필요한 규칙

| 항목 | 현재 처리 | 남은 판단 |
| --- | --- | --- |
| 특이 만료일 | 날짜를 보존하고, 기간이 역전된 5건은 현행 기간 조건에서 제외합니다. | `9999-01-01`이 무기한·미정 표시인지 확인하고, 역사적으로 이례적인 날짜의 정정 근거와 포함 기준을 정합니다. |
| 취소·철회·이의 제기 | 상태와 변경일을 보존합니다. | 변경일이 기간에 미치는 영향과 당일 포함 기준을 정합니다. |
| 미등록 상태 | `INQ` 1건을 검토 대상으로 기록합니다. | 코드의 의미와 공용 코드표 반영 여부를 확인합니다. |
| 복수 기간 후보 | 후보 수와 복수 매칭 상태를 남깁니다. | 신청 유형이나 상태를 근거로 확정할 수 있는지, 미확정 건을 어떻게 집계할지 합의합니다. |
| 사업장 식별과 이력 | 계정번호와 사업장 번호의 조합을 사업장 키에 사용합니다. | 이전·속성 변경 시점의 사업장 이력을 어떤 기준으로 복원할지 정합니다. |
